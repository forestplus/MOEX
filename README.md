# MOEX — Тепловая карта российского фондового рынка

Статический сайт (GitHub Pages) для оценки состояния рынка: тепловые карты акций,
облигаций и внебиржевого рынка, новости, избранное и аналитика портфеля БКС.

## Страницы

| Файл | Страница |
|---|---|
| `index.html` | Тепловая карта акций (TQBR): день/неделя/месяц, сводка рынка, карточка бумаги со свечами, дивидендами и новостями |
| `bonds.html` | Тепловая карта облигаций: доходность, дюрация, купоны, ОФЗ |
| `otc.html` | Внебиржевой рынок акций (`?type=ru` / `?type=foreign`) |
| `favorites.html` | Избранное (акции + облигации), настройка собственного CORS-прокси |
| `news.html` | Новости рынка из RSS-лент |
| `portfolio.html` | Портфель БКС: позиции, P/L, структура, свободные деньги |

## Структура репозитория

```
src/                  исходники страниц (*.src — НЕ редактировать *.html вручную!)
  shared/core.js      общие утилиты (//@import встраивает их при сборке)
build_protected.js    сборка: шифрует страницы паролем (AES-256-GCM + PBKDF2)
worker.js             Cloudflare Worker — собственный CORS-прокси (опционально)
bcs/                  интеграция с БКС Trade API (Python)
data/                 JSON-выгрузки от GitHub Actions (bcs_portfolio.json, bcs_quotes.json)
.github/workflows/    автоматика
```

## Сборка и публикация

Готовые `*.html` — это зашифрованные исходники из `src/`. После изменения исходников:

```bash
MX_LOGIN=логин MX_PASSWORD=пароль npm run build   # собрать все страницы
git add *.html && git commit -m "rebuild" && git push
```

Логин/пароль нигде не сохраняются: неверный пароль просто не расшифрует страницу.

## Данные

- Котировки, свечи, стакан, купоны — **MOEX ISS API** напрямую из браузера (без ключей).
- Дивиденды, мультипликаторы — smart-lab через цепочку CORS-прокси
  (напрямую → allorigins → corsproxy; свой прокси — `worker.js`).
- Новости — RSS (РБК, Интерфакс, Коммерсантъ, Ведомости, Smart-lab, Финам, Investing, ТАСС, РИА).

## Интеграция с БКС

Документация API: <https://trade-api.bcs.ru> (сам API живёт на `be.broker.ru`).

1. В «БКС Мир инвестиций» выпустите токен API **«только для чтения»**
   (Профиль → счёт → Токены API).
2. Добавьте его в секреты репозитория: `BCS_API_KEY_READ`.
3. (Рекомендуется) добавьте секрет `GH_PAT` — fine-grained personal access token
   с правом **Secrets: write** на этот репозиторий. Он нужен, чтобы workflow
   автоматически обновлял `BCS_API_KEY_READ`, когда БКС ротирует refresh-токен.
   Без него после ротации придётся обновлять секрет руками.
4. Workflow **BCS API** (`.github/workflows/bcs.yml`) каждые 30 минут в торговые
   часы проверяет токен, выгружает портфель в `data/bcs_portfolio.json` и котировки
   в `data/bcs_quotes.json`, коммитит их обратно. Страница «Портфель» читает этот файл.

Памятка по токенам БКС: access живёт 24 часа, refresh — 90 суток и ротируется
при каждом обмене. За ~10 дней до истечения БКС пришлёт напоминание — перевыпустите
токен и обновите секрет.

Локальная проверка (нужен `pip install requests`):

```bash
export BCS_API_KEY_READ=...
python bcs/check_token.py        # проверка токена и срока его жизни
python bcs/export_portfolio.py   # выгрузка портфеля в data/
```

## Планы

- Токен «для торговли и чтения» (`trade-api-write`) и торговый бот:
  заявки через `POST /trade-api-bff-operations/api/v1/orders` (см. `bcs/bcs_client.py`).
